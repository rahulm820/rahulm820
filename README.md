## 🏗️ Featured Projects

### 🧠 [Cognivest](https://github.com/rahulm820/cognivest) — Per-Company Financial Intelligence Platform
> Fuses **price action** with **news/web narrative** into a unified per-ticker knowledge graph to answer questions like *"Why did $AAPL drop on March 3?"* with cited sources.

- **Tech:** FastAPI, Next.js 14, TypeScript, **Cognee**, Kuzu (graph DB), LanceDB (vectors), Gemini, PostgreSQL, Redis, Docker.
- **Architecture:** Four-stage AI memory lifecycle — **Remember → Recall → Improve → Forget** — with per-ticker dataset isolation and a single mockable Cognee seam. Runs end-to-end on free tiers with **zero infra cost**.

### ⚽ [FIFA Rapid Agent 2026](https://github.com/rahulm820/GRAHFifa) — AI Football Companion App

- **Architecture:** Multi-agent backend orchestrating live match data with screen-context injection and dynamic live-score capsules.

## 🌐 Open Source Contributions

### [topoteretes/cognee-rs](https://github.com/topoteretes/cognee-rs) — Rust AI Memory Engine
> Contributor to the high-performance Rust engine powering the [Cognee](https://github.com/topoteretes/cognee) AI-memory platform (boots in ~350ms, embedded SQLite + Ladybug + LanceDB).

**🔗 [PR #25](https://github.com/topoteretes/cognee-rs/pull/25) — `spike(wasm)`: Run logic-only crates on `wasm32` (browser-verified)** &nbsp;<img src="https://img.shields.io/badge/Merged-8957E5?style=flat&logo=github&logoColor=white" alt="Merged" />

- Made three core crates (**`cognee-utils`, `cognee-models`, `cognee-chunking`**) compile and run on **`wasm32-unknown-unknown`**, verified end-to-end in a **headless Chrome** browser — not just Node.
- Resolved deep WASM incompatibilities: `getrandom`/`uuid` randomness backends, Tokio runtime features, filesystem gating, and `chrono` time traps — all behind `#[cfg(target_arch = "wasm32")]` guards so **native builds stay untouched**.
- Swapped `tokio::time::sleep` → `futures_timer::Delay` for cross-platform retry backoff, and added **dedicated CI lanes** (Node + headless Chrome) plus a drift-guard to prevent regressions.
